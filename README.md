# CROPSICLES

A crop-circle match-3, built on an original neon-vector engine in Unity 6.

Match glowing crop-circle discs across four hand-tuned worlds, chain cascades into
galactic-harvest combos, and go head-to-head in real-time 1v1 VERSUS.

## The game

- **Four worlds, twelve levels** — a hand-authored difficulty curve with a three-star
  skill objective on every stage.
- **Original art and engine** — every disc, particle, aurora, and UI surface is drawn
  by our own immediate-mode vector renderer and our own 3D crop-circle discs. No
  third-party game assets; no reskin.
- **Live 1v1 VERSUS** — same-seed deterministic matches over the Oddsockets realtime
  SDK, with presence, in-match chat, and a worldwide harvest leaderboard.
- **Handcrafted juice** — feed-the-score count-ups, combo callouts, cascade flashes,
  screen-shake on big hits, and a full achievement celebration.

### First launch
- **macOS** — unsigned build: right-click the app → **Open**, or clear quarantine with
  `xattr -dr com.apple.quarantine CROPSICLES.app`.
- **Windows** — SmartScreen may warn: **More info → Run anyway**.
- **Linux** — `chmod +x CROPSICLES.x86_64`, then run.

## Technology

Unity 6 · a bespoke immediate-mode neon-vector renderer · live 3D crop-circle discs ·
the Oddsockets realtime SDK (pub/sub, presence, state channels, chat, history) ·
a GameCI build pipeline across macOS, Windows, and Linux.
